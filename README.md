# Student Registration System

## Aim
To develop a student registration webpage and automate build and testing using Jenkins and GitHub Actions.

## Features
- Student name, email, roll number and course fields
- HTML, CSS and JavaScript based registration form
- Form validation and success message
- Automated Python unit tests
- Jenkins pipeline for build and test
- GitHub Actions workflow for automatic testing

## Project Files
- index.html - Registration form
- style.css - Page styling
- script.js - Form validation
- test.py - Automated tests
- Jenkinsfile - Jenkins pipeline
- .github/workflows/test.yml - GitHub Actions workflow

## Run Automated Tests
Run the following command in PowerShell:

    py test.py

## Tools Used
HTML, CSS, JavaScript, Python, Jenkins, Git and GitHub Actions.
